## 三、比赛中：每来一条新闻

### 先问三个问题

1. **影响哪只？**（MACRO = 全部）
2. **利好还是利空？**这条新闻会让公司**多赚钱**还是**少赚钱**？对 **ESG** 是加分还是扣分？
3. **这只现在占多少？**

### 然后这样做

| 新闻 | 操作 |
|---|---|
| 利好 / ESG 加分 | 在 30% 以内加仓这只 |
| 利空 / ESG 扣分 | 减到 10% 至 15%，**卖完马上买进另一只** |
| MACRO 利好（降息、刺激） | 保持高投资比例，可以多配科技（NVDA、TSLA） |
| MACRO 利空（加息、通胀超预期） | 科技股（NVDA、TSLA）冲击通常更大，可以挪一部分到能源（EDF、RDS、SIE） |

### 每只股票：可能出现的新闻方向

| 股票 | 利好可能是 | 利空可能是 |
|---|---|---|
| EDF | 新的可再生项目、减排成果、业绩回升 | 项目延误、核电问题、业绩不及预期 |
| TSLA | 交付量创新高、新车型 | CEO 争议言论、自动驾驶 / AI 系统问题、召回 |
| NVDA | 业绩超预期、新业务扩张 | 加息、供应链问题、ESG 目标落空 |
| SIE | 风电业务改善、管理层稳定 | 高层再次变动、风电项目问题 |
| RDS | 油价上涨、减排进展 | 漏油事故、新的环保诉讼 |

## 四、每隔一分钟扫一眼

| 看哪里 | 要求 |
|---|---|
| 顶部 **Available cash** | 不超过约 **100 万至 200 万**（要求是全部投出去） |
| 持仓表 **% OF PORTFOLIO** | 每只都在 **10% 至 30%**（分散） |
| 持仓表 **UNREALISED P/L** | 每只都不低于 **−40 万**（离 50 万止损留缓冲） |

## 五、三条铁律

1. **调仓全部找银行**，交易所只做几十万美元以内的小单。
2. **卖和买成对出现**：卖掉一只，马上买进另一只。
3. **不要来回折腾**：想好了再动，动一次就够。
